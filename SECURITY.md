# Security policy

Please report vulnerabilities privately to **security@zenstaff.app** (or through GitHub's
"Report a vulnerability" button on this repository). Do not open a public issue.

Include what is affected (hub, memory, the compose setup), the version or commit, and the steps to
reproduce. We confirm receipt within 3 working days and tell you what we will do and when. We
credit reporters in the release notes unless you prefer not to be named.

Supported versions: the latest release of this repository. Self-hosters should upgrade promptly
(`git pull && docker compose up -d --build`).
